# デスクトイ・バトル

机の上のカッターマットで遊ぶ、2対2のオンライン対戦ゲームです。船が積み木を港へ運び、サメがそれを邪魔します。

## 起動

```
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。友達と遊ぶときは、同じネットワークから `http://<このPCのIPアドレス>:3000` を開いてもらいます。ポートは環境変数 `PORT` で変えられます。

## 遊び方

タイトル画面で4つの遊び方を選べます。

- ひとりで遊ぶ: CPUの強さ(やさしい / ふつう / つよい)を選ぶと、味方1人と相手2人をボットにしてすぐに始まります。
- ランダムマッチ: 待っている人と自動で組みます。30秒たっても4人そろわなければ、足りない分をボットで埋めて始まります。
- 友達とルームを作る: 4文字のルームコードが出るので、友達に伝えます。ホストが「開始する」を押すと始まり、足りない分はボットが入ります。ボットの強さはロビーでホストが選べます。
- タイトルの「ひとりで遊ぶ / ランダムマッチ / 友達とルーム / ルームに参加」は、本編(船とサメ)とミニゲームを順番に遊ぶ連戦です。本編1回のあとにミニゲーム3つ、の順で出てきます。オンラインでは2人で遊び、本編は2人が別チームになって残りをCPUが担当します。
- ゲームをえらぶ: 本編と机の上の物で遊ぶミニゲーム10種類(ケシバト、文具アスレチック、輪ゴムの的当て、クリップ釣り、付箋の神経衰弱、文具つみ、定規カーリング、紙ずもう、キャップホッケー、画鋲よけ)から1つを選んで遊びます。本編は従来どおり4人まで遊べます。ミニゲームは、ひとり(CPU)、ランダムマッチ、友達とのルームで2人対戦ができます。
- ルームに参加: 友達から聞いたコードを入力します。

全4ラウンド(1ラウンド最大100秒、資材8個)で、ラウンドごとに船(運ぶ側)とサメ(邪魔する側)が入れ替わります。

- 移動: WASD または矢印キー / スマホは左下のスティック
- 船: ダッシュ(Space)、保護(Shift。短時間、積み荷を落とさない)
- サメ: 突進(Space。当たると積み荷を全部落とす)、潜行(Shift。相手から見えにくくなる)

マットの印刷が地形です。太い線(航路)では船が速く、同心円(渦)では船が遅くサメが速くなります。角の扇形の中ではサメの突進が強くなります。

## 得点

- 運搬側: 運んだ1個につき1点。全部運ぶと+3点、早く運び切るほど残り時間ボーナス(最大+2点)。
- 妨害側: 落とさせた資材1個につき1点(同じ資材はラウンド中1回まで)。時間切れまで守り切ると+3点。
- 運んだ数がちょうど半分で時間切れなら引き分けで、両チームに同点(初期値6点)。
- 4ラウンドの合計で勝敗を決めます。同点なら引き分けです。

## 調整

定数はすべて `shared/config.js` にあります。主なもの:

- `ROUND_TIME` ラウンドの秒数 / `BLOCKS` 資材数 / `BOAT_CAPACITY` 船の積載数
- `BOAT.speed` `SHARK.speed` 移動速度、`dashCd` `protectCd` `chargeCd` `diveCd` 各クールダウン
- `TERRAIN` 航路・渦・扇形の効果と位置、`OBSTACLES` 机の小物の配置
- `SCORE` 得点の配分

## インターネットに公開する(Render の無料プラン)

自分のPCを起動したままにしなくても、どこからでも遊べるようになります。

1. GitHub に新しいリポジトリを作り、このフォルダの中身(node_modules 以外)を入れます。
2. https://render.com に GitHub アカウントでサインアップします。
3. 「New +」から「Web Service」を選び、1のリポジトリを選びます。
4. 次のように設定して「Create Web Service」を押します。
   - Language: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
5. 数分で `https://〇〇.onrender.com` のアドレスができます。これを友達に送れば遊べます。

無料プランは15分ほど誰もアクセスしないと休止します。休止中に開くと、表示まで1分ほどかかります。

## ご意見(フィードバック)

タイトル右上の「ご意見」から、だれでも短い文を送れます。届いた文は次の場所に残ります。

- いつでも: Render のダッシュボードの Logs に `[feedback]` で始まる行として出ます(再起動で古いものは消えます)。
- 設定すれば: GitHub のこのリポジトリの Issues に、ラベル `feedback` 付きで1件ずつ登録されます。Render の Environment に `GITHUB_TOKEN`(このリポジトリの Issues に書き込める Fine-grained token)を追加してください。別のリポジトリに送るときは `FEEDBACK_REPO`(例: `owner/repo`)も設定します。
